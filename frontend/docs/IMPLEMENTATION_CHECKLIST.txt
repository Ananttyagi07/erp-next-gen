                            DEPLOYMENT INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════════

Step 1: Database Setup (2 minutes)
  Run: cd backend
       python manage.py makemigrations front_office
       python manage.py migrate front_office

Step 2: Backend Verification (1 minute)
  Run: python manage.py runserver
  Test: http://localhost:8000/api/front_office/visitor-purposes/
  Expected: API response with auth token required message

Step 3: Frontend Verification (1 minute)
  Run: cd frontend
       npm run dev
  Access: http://localhost:5173/

Step 4: Module Testing (5 minutes)
  1. Login to the application
  2. Navigate to "Front Office" in sidebar
  3. Test each of 5 sub-modules
  4. Create/edit/delete records
  5. Test search and pagination
