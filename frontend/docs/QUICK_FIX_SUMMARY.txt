                            LOGIN ISSUE - FIXED ✅
═══════════════════════════════════════════════════════════════════════════════

PROBLEM:
  The LoginView endpoint had permission_classes = [IsAuthenticated]
  This prevented unauthenticated users from logging in (impossible paradox!)

SOLUTION:
  Changed LoginView permission_classes from [IsAuthenticated] to [AllowAny]

FILE CHANGED:
  ✅ backend/apps/authentication/views.py (line 52)

CHANGE MADE:
  BEFORE: permission_classes = [IsAuthenticated]  ❌
  AFTER:  permission_classes = [AllowAny]          ✅

WHY THIS WORKS:
  - AllowAny allows unauthenticated users to access login
  - IsAuthenticated requires user to be already authenticated (defeats login!)
  - Other endpoints (logout, refresh, etc.) correctly use IsAuthenticated
