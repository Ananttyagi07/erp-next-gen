API ENDPOINT EXAMPLE
═══════════════════════════════════════════════════════════════════════════

Create Student (POST):
  URL: /api/students/
  Method: POST
  Headers: Content-Type: application/json, Authorization: Bearer <token>
  Body: {...formData with all fields...}
  Response: { id, message, success }

List Students (GET):
  URL: /api/students/
  Method: GET
  Headers: Authorization: Bearer <token>
  Query: ?school=<id>&page=1&limit=15
  Response: { count, results: [...], next, previous }

Update Student (PATCH):
  URL: /api/students/{id}/
  Method: PATCH
  Headers: Content-Type: application/json, Authorization: Bearer <token>
  Body: {...updated fields...}
  Response: { id, ...updated fields, success }

Delete Student (DELETE):
  URL: /api/students/{id}/
  Method: DELETE
  Headers: Authorization: Bearer <token>
  Response: { success, message }

COMMON CUSTOMIZATIONS
═══════════════════════════════════════════════════════════════════════════

Change primary color from black to blue:
  Find: bg-black text-white
  Replace: bg-blue-600 text-white
  Note: Also update focus:ring-black to focus:ring-blue-600

Add new form field:
  1. Add to formData state
  2. Component auto-handles in handleFormChange
  3. Add JSX with FormField wrapper
  4. Add to validation if required

Connect to API:
  1. Replace handleSubmit function
  2. Add fetch/axios call
  3. Handle loading state
  4. Display success/error messages

Load data in table:
  1. Add useEffect hook
  2. Fetch students from API
  3. Map students in table rendering
  4. Add loading/error states

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Icons not showing?
  → npm install lucide-react
  → Check import statements

Styles not applying?
  → Ensure Tailwind CSS is configured
  → Check tailwind.config.js content paths
  → Rebuild Tailwind CSS

Form not submitting?
  → Check console for validation errors
  → Ensure all required fields are filled
  → Check API endpoint in handleSubmit

Table not showing data?
  → Check data structure matches schema
  → Add error handling in data fetch
  → Verify pagination logic

Mobile layout broken?
  → Check responsive classes (md:, lg:)
  → Test viewport in DevTools
  → Review grid column settings
